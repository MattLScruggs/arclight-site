The Arclight Toolkit

Building local AI/ML solutions for public health

NoteThe Problem

Practical implementation of machine learning and artificial intelligence is significantly lacking on the front lines of public health. While many proposed solutions show promise in controlled academic settings, actual implementation is challenged by data fragmentation, data bias, privacy concerns, domain oversights, or a reliance on computing infrastructure unavailable to under-resourced local health departments.

Whether the health emergency is a new outbreak of an existing pathogen, a novel virus, a drug-resistant fungus, an environmental toxin, or a bioterror attack, the first contact between pathogen and the public health system will be the outbreak investigation conducted by local health departments. The impact generated by aiding this process with ML/AI tools is considerable, and currently unaddressed.

What is Arclight?

Arclight is an open-source, cross-platform, on-device machine learning and AI toolkit for epidemiologists and public health professionals designed to provide decision support during an outbreak investigation.

In its final form, the application, running on an end-user’s device, will bring in information in the form of images, text, or audio, process the information locally, and generate outputs in the form of text, charts, graphs, maps, or other helpful decision support aides through the use of various machine learning and AI models.

Design Goals and Exclusions

Arclight will assist field epidemiologists and public health professionals when investigating potential infectious disease outbreaks. Arclight will exclusively process information on-device to protect PHI, eliminate infrastructure costs, and add direct oversight by the end-user.

Specific Arclight functions will evolve over time, but will generally will be designed to support epidemiologists during the following phases of an outbreak investigation: - Integrating existing public health surveillance data - Processing case reports and investigative notes - Refining the case definition based on collected information and alternative diagnoses - Organizing case reports based on population, location, and time - Developing etiological hypotheses based on observed notes and reference data.

Arclight deployment will include only Android, iOS, and Windows devices. Model performance will be constrained by the demands of on-device processing, to include available modules in the required tech stack. Arclight will not replace established decision support tools used for policy development, outbreak forecasting, or other use cases requiring large data sets and server-grade processing power; rather, it fills a gap at the local level.

Technical Methodology and Implementation:

Arclight’s architecture is built on a modular, cross-platform framework that prioritizes on-device execution to ensure absolute privacy for Protected Health Information (PHI) and independence from cloud infrastructure. The methodology for integrating machine learning capabilities into the application is divided into model development and front-end integration.

Model Development and Export

Each machine learning and AI model is developed independently as a standalone module to ensure ease of testing, rapid iteration, and separation of concerns.

  • Environment: Models are developed using Visual Studio Code (VSCode).

  • Framework: TensorFlow is utilized for model training, evaluation, and optimization.

  • Optimization & Export: Once trained, models are optimized for mobile and desktop on-device execution and exported into the lightweight TensorFlow Lite (.tflite) format.

Flutter and Dart Integration

The core application is built using the Flutter framework, enabling a single codebase to deploy across Android, iOS, and Windows. For each machine learning function or utility module, a standardized, sequential process is followed within the Dart codebase:

  • Front-End Design: Develop the responsive front-end user interface components in Flutter to capture inputs (text, audio, images).

  • Data Import & Preprocessing: Write robust data ingestion and preprocessing handlers in Dart to prepare inputs for model compatibility.

  • Model Execution: Invoke the exported .tflite model locally using the tflite package for Dart, passing the preprocessed inputs to the model.

  • Output Formatting: Capture the inference results, process and format them (generating charts, tables, maps, or textual decision support), and display them within the UI.

This modular workflow is replicated dynamically for every machine learning model integrated into Arclight.
